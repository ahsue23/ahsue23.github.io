# 아슈부부 링크 모음

별도 설치나 빌드 없이 GitHub Pages에서 제공하는 정적 웹사이트입니다.

## 링크와 카드 수정

`links.js`의 `featured`에서 고정 링크 주소를 수정합니다. 고정 카드의 글씨와 그림은 이미지에 포함되어 있어, 제목 자체를 바꾸려면 해당 에셋도 수정해야 합니다.

`extra`의 항목을 복사하거나 삭제해 **함께하는 이야기** 카드를 관리합니다.

```js
{
  title: "큰 글씨 제목",
  description: "작은 글씨 설명",
  url: "https://example.com",
},
```

- 표시 순서대로 왼쪽 / 오른쪽 노란 테이프가 자동으로 반복됩니다.
- 제목이 없거나 `url`이 비어 있거나 유효한 웹 주소가 아니면 그 카드는 표시하지 않습니다.
- `extra: []`로 비우면 제목·소개·구분선까지 섹션 전체가 사라지고 문의 영역이 올라옵니다.
- `email`을 바꾸면 화면의 이메일 주소, 이메일 링크, 복사되는 주소가 함께 바뀝니다.
- `openInNewTab: true`로 바꾸면 카드 링크가 새 탭에서 열립니다.

## 디자인

- 화면이 넓어져도 본문은 최대 480px 너비로 가운데 정렬됩니다.
- 좁은 화면에서는 그림 비율을 유지하며 줄어듭니다. 양옆은 원본 배경색 `#e8d6ba`로 이어집니다.
- 추가 카드의 제목은 어비 세현체, 설명은 이서윤체를 사용합니다. 제공받은 폰트를 WOFF2로 압축해 사용하며, 다른 글자를 추가해도 되도록 전체 글리프를 유지했습니다.
- 그림은 `assets/artwork/`, 웹 폰트는 `assets/fonts/`에 있습니다. 고정 카드는 `featured-youtube.webp`, `featured-blog.webp`, `featured-studio.webp`, `featured-shop.webp`로 각각 분리되어 있습니다.
- 마우스를 올리면 고정 카드와 추가 카드가 각각 2px 위로 움직입니다. 움직임 줄이기를 설정한 기기에서는 이동 효과를 끕니다.
- 문의 주소는 버튼으로 복사하며, 자동 복사가 차단되면 직접 복사할 수 있는 주소 입력란을 표시합니다.

## 로컬 확인

이 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`을 열면 됩니다.
